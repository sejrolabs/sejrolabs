**Technologies :** Python, Pandas, XGBoost, Scikit-learn, SHAP.

### 2. Credit Card Fraud Detection

Built machine learning models to identify fraudulent transactions in a highly imbalanced dataset of **285,807 transactions**, with a fraud rate of approximately **0.17%**.

- Compared Random Forest and XGBoost approaches.
- Evaluated class weighting and sampling strategies.
- Optimized the precision-recall trade-off.
- Achieved **87.2% precision and 83.7% recall** with the selected model.

**Technologies :** Python, Pandas, Scikit-learn, XGBoost, Imbalanced-learn.

[View project on GitHub](PROJECT_REPOSITORY_URL) - [Live demo](PROJECT_DEMO_URL)
